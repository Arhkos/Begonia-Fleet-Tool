# Politique de Securite / Security Policy

## Signalement d'une Vulnerabilite

Si vous decouvrez une vulnerabilite de securite dans ce projet, **veuillez ne pas creer d'Issue GitHub publique**.
Contactez le mainteneur via un **[GitHub Security Advisory prive](https://github.com/Arhkos/Begonia-Fleet-Tool/security/advisories/new)**.
Nous nous engageons a accuser reception dans un delai de **48 heures**.

### Versions Supportees

| Version | Support Securite |
|---|---|
| `main` (derniere) | Supportee |
| Versions anterieures | Non supportees |

---

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public GitHub Issue**.
Contact the maintainer via a **[private GitHub Security Advisory](https://github.com/Arhkos/Begonia-Fleet-Tool/security/advisories/new)**.
We commit to acknowledging your report within **48 hours**.
